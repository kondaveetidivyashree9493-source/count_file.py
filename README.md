# Count Characters, Words, and Lines in a File

## Aim
To write a Python program that reads a file and counts the number of characters, words, and lines.

## Requirements
- Python 3
- Input file named `example.txt`

## Functions Used
1. `open()` – Opens the file.
2. `readlines()` – Reads all lines.
3. `split()` – Separates text into words.
4. `len()` – Counts characters and words.
5. `try-except` – Handles file errors.

## Algorithm
1. Open the file in read mode.
2. Initialize character, word, and line counters.
3. Read each line from the file.
4. Count characters, words, and lines.
5. Print the total counts.
6. Handle file-related errors.

## Sample Input (`example.txt`)
```text
Hello Python
Welcome to programming
```

## Expected Output
```text
Characters: 36
Words: 5
Lines: 2
```

## Result
The program successfully counts and displays the total number of characters, words, and lines in a file.
